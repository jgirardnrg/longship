# Longship 0.3.1 alpha

- Fixes missed player alerts following a temporary companion-bridge outage.
- Queues audio so rapid events across servers play completely in order.
- Keeps notification playback active when Longship is hidden in the system tray.
- Adds a descending departure chime. The existing per-server speaker toggle controls joins and departures.

Unsigned Windows installer and portable builds and Linux packages include SHA-256 checksums. A launcher restart is needed to activate this update.
