# Longship 0.3.2 alpha

- Choose custom join and departure sounds per server from Overview → Sound settings.
- Adjust each sound from 0–100%, preview it, or restore the default sound. Settings save immediately and can change while a server is running.
- WAV, MP3, OGG, FLAC and M4A files are checked for playback support and copied into Longship data so moving the originals does not break alerts.
- Retains queued playback and hidden-window player notifications from 0.3.1.

Unsigned alpha packages include SHA-256 checksums. Restart the launcher to activate the update.
